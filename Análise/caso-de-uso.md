# Casos de Uso

## Caso de uso 1: Fazer pedido
- **Ator:** Cliente
- **Descrição:** Cliente seleciona produtos, adiciona ao carrinho e confirma pedido.
- **Resultado esperado:** Pedido registrado no sistema e exibido no painel do administrador.

## Caso de uso 2: Gerenciar pedidos
- **Ator:** Administrador
- **Descrição:** Visualiza lista de pedidos, atualiza status (pendente, em preparo, pronto).
- **Resultado esperado:** Todos os pedidos atualizados e exibidos corretamente para a equipe.

## Caso de uso 3: Cadastro de produtos
- **Ator:** Administrador
- **Descrição:** Adiciona, edita ou remove produtos do cardápio.
- **Resultado esperado:** Cardápio atualizado e disponível para pedidos.
