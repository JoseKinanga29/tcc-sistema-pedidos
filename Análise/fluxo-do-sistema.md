# Fluxo do Sistema

1. Cliente acessa o sistema e visualiza o cardápio.
2. Cliente seleciona produtos e adiciona ao carrinho.
3. Cliente confirma o pedido.
4. Pedido é registrado no banco de dados e exibido no painel do administrador.
5. Administrador verifica o pedido e atualiza status (pendente → em preparo → pronto).
6. Cliente e equipe recebem atualização sobre o status do pedido.
7. Sistema gera relatório diário resumindo pedidos e produtos mais vendidos.
