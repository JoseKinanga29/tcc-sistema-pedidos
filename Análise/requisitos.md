# Requisitos do Sistema.

### Funcionalidades do Sistema ###
📌 MENU DIGITAL
     * O Cliente visualiza os produtos com imagens, preço e descrição
     * O cliente poderá filtrar por categorias (lanches, bebidas, etc)
     * O menu pode atualizar automaticamente quando o restaurante muda o cardápio no painel do administrador.

📌 Carrinho de Compras
      * O cliente adiciona os produtos que deseja comprar.
      * O sistema calcula o total automaticamente.
      * Antes de confirmar, o cliente poderá editar, remover ou adicionar ítens.

📌 Painel de pedidos (para a cozinha)
      * Mostra todos os pedidos recebidos em tempo real.
      * O cozinheiro pode marcar o status do pedido, ex: em preparo, pronto ou entregue.
      * Cada mudança de status é atualizada instantaneamente na tela do cliente.

📌 Controle de Status
      * O cliente acompanha o processo do pedido em tempo real.
      * Poderá também receber uma notificação quando o pedido foi concluído.

📌 Relatório e recibos
      * O sistema gera um recibo automático com os detalhes do pedido, data, valor total e forma de pagamento.
      * Pode ser exportado em PDF, ou enviar por e-mail ou whatsapp.
      * Para o dono/adm, poderá haver relatório diário das vendas.
